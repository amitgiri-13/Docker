# Docker Commands — From Basic → Advanced

---

#  1. BASIC COMMANDS (Foundation)

These are the commands you’ll use daily.

##  Docker Version & Info

```bash
# Shows the installed Docker CLI version on your system
docker --version 

# Detailed version information for both Docker client and Docker Daemon
docker version

# System-wide information about Docker, including containers, images, storage, and runtime
docker info
```

##  Image Management

```bash
# Pull images with default tag: latest
docker pull nginx

# Pull images with specific tag: 20.04
docker pull ubuntu:20.04

# List images
docker images

# Remove imges
docker rmi <image_id>

# Remove unused (dangling) images
docker image prune

# Remove unused (dangling and unreferenced) images
docker image prune -a

```

##  Container Lifecycle

```bash
# Creates and starts a new container from the nginx image in the foreground
docker run nginx

# Runs an nginx container in detached mode in the background
docker run -d nginx

# Starts an interactive ubuntu container with a Bash shell attached to your terminal
docker run -it ubuntu bash

# Runs nginx and maps host port 8080 to container port 80 for external access.
docker run -p 8080:80 nginx

# Runs an nginx fcontainer and assings it the custom name "mycontainer"
docker run --name mycontainer nginx
```

##  Start / Stop / Remove

```bash
# Start the container
docker start <container>

# Stop the container
docker stop <container>

# Re-start the container
docker restart <container>

# Remove the container
docker rm <container>

# Forcefuly stops and removes the container
docker rm -f <container>

# Remove all stopped containers
docker container prune
```

##  View Containers

```bash
# View all running containers
docker ps

# View all containers
docker ps -a
```

##  Logs & Exec

```bash
# Displays the logs/output generated by a container
docker logs <container>

# Stream and continuously follows the container's logs in real time
docker logs -f <container>

# Opens an interactive Bash shell inside a running container
docker exec -it <container> bash
```

#  2. INTERMEDIATE COMMANDS

Used in real development workflows.

---

##  Building Images

```bash
# Build image
docker build -t myapp .

# Build image with the tag
docker build -t myapp:v1 .
```

##  Tag & Push Images

```bash
# Tag image myapp 
docker tag myapp username/myapp:v1

# Push image to registry
docker push username/myapp:v1
```

##  Inspecting Objects

```bash
# Shows detailed low-level configuration and runtime information about a container
docker inspect <container>

# Displays detailed metadata and configuration details of a Docker image
docker inspect <image>
```

##  Environment Variables

```bash
# Set environment  variable for the container
docker run -e ENV=prod nginx
```

##  Volumes (Persistent Storage)

```bash
# Creates a new Docker volume namded myvol for persistend storage
docker volume create myvol

# Mounts the myvol volume inside the container at /data
docker run -v myvol:/data nginx

# Lists all Docker volumes on the system
docker volume ls

# Shows detailed information about the myvol volume
docker volume inspect myvol

# Deletes the myvol volume from the system
docker volume rm myvol
```

##  Bind Mounts

```bash
# Mounts the current host directory into the container at /app for live file sharing between host and container
docker run -v $(pwd):/app nginx
```

##  Networks

```bash
# List all Docker networks on the system
docker network ls

# Creates a new Docker network named mynet
docker network create mynet

# Runs an niginx container attached to the mynet network in detached mode
docker run -d --network mynet nginx

# Shows detailed configuration and connected containers of the mynet network
docker network inspect mynet
```

##  Copy Files

```bash
# Copies a file from the host (file.txt) into the container at /app
docker cp file.txt <container>:/app

# Copies a file from the container (/app/file.txt) to the current directory on the hoost
docker cp <container>:/app/file.txt .
```

##  Save & Load Images

```bash
# Export myapp image into a tar archive file for backup or transfer
docker save myapp > myapp.tar

# Imports a Docker image from a tar archive back into the local Docker system
docker load < myapp.tar
```

#  3. ADVANCED COMMANDS (DevOps / Production)

Used in CI/CD, Kubernetes, system debugging, optimization.

---

##  Docker System Management

```bash
# Shows the disk usage of Docker images, container, volumes, and build cache.
docker system df

# Removes stopped containers, unused networks, and dangling images to free up space
docker system prune

# Reemoves all unused containers, networks, dangling images, and unreferenced images to reclaim manximum disk space
docker system prune -a
```

##  Resource Limits

```bash
# Runs an nginx container with a memory limit of 512 MB
docker run -m 512m nginx

# Runs an nginx container limited to using 1.5 CPU cores
docker run --cpus="1.5" nginx
```

##  Health Checks

```bash
# Runs an nginx container with a health check that marks it unhealthy if 'http:/;/localhost' is not reachable
docker run --health-cmd="curl -f http://localhost || exit 1" nginx
```

##  Restart Policies

```bash
# Automatically restarts the nginx container if it stops or the Docker daemon restarts
docker run --restart always nginx

# Restarts the container on failure or daemon restarts, unless it was manually stopped
docker run --restart unless-stopped nginx
```
---

##  Docker Events (debugging)

```bash
# Streams real-time events from the Docker Daemon, such as container start, stop, or network changes
docker events
```

##  Stats (Monitoring)

```bash
# Displays real-time resource usage (CPU, memory, network, I/O) for running containers
docker stats
```

##  Top (processes inside container)

```bash
# Shows the running processes inside a specific container
docker top <container>
```

---

##  Export & Import Container

```bash
# Exports teh filesystem of a container to a tar archive
docker export container > container.tar

# Creates a new Docker image from a tar archive exported from a container
docker import container.tar myimage
```

---

##  Docker Context (multi environment)

```bash
# Lists all Docker contexts, showing different Docker environments you can switch between
docker context ls

# Create context mycontext
docker context create mycontext --docker "host=ssh://user@hostname"

# Switch context
docker context use default
```

---

##  Login / Logout

```bash
# Authenticates your Docker client with a registry (like Docker Hub) to push or pull private images
docker login

# Logs out from a Docker Registry, removing your saved authentication credentials
docker logout
```

#  4. DOCKER COMPOSE COMMANDS (Very Important)

For multi-container apps.

```bash
# Creates and starts all services defined in the compose file in foreground
docker compose up

# Creates and starts all services defined in the compose fiel in the background
docker compose up -d

# Stops and removes all containers, networks, and default volumes created by docker compose up
docker compose down

# Lists all running containers and their status for the current compose
docker compose ps

# Shows the logs of all services defined in the compose file
docker compose logs

# Builds or rebuilds images for services defined in the compose file
docker compose build

# Restarts all running ser vices defined in the compose project
docker compose restart
```

#  5. USEFUL REAL-WORLD COMMAND COMBINATIONS

### Run NGINX in background with port mapping

```bash
# Runs an nginx container int the background, names it web, and maps host port 80 to container port 80
docker run -d -p 80:80 --name web nginx
```

### Debug inside running container

```bash
# Opens an interactive bash shell inside the runnign web container for debugging
docker exec -it web bash
```

### Remove everything (cleanup)

```bash
# Cleans up all usuded containers, images, networks, and volumes to free disk space
docker system prune -a --volumes
```
